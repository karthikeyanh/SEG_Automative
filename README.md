# SEG_Automative
This repository is a catalogue application devlopment repositry for SEG Automative
A unified, read-only product catalogue across Web, Android, and iOS for SEG Automotive products.
## Tech Stack
- **Web**: React + Vite
- **Mobile**: Flutter (Android & iOS)
- **Backend**: Node.js + Express.js
- **Database**: PostgreSQL 16 (Faculty provided)
## Project Structure
- \`apps/web/\` - React Web Application
- \`apps/mobile/\` - Flutter Android & iOS Application
- \`backend/\` - Express.js REST API
- \`database/\` - Schema reference & lookup data
- \`docs/\` - API documentation & architecture
